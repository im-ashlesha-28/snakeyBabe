# 🎀 snakey babe 🎀

A totally girly, ultra-kawaii version of the classic Snake game, built in Python using Pygame! Playable natively on desktop or directly in the browser. 💖

## 🍓 Features
* **Kawaii Aesthetics:** A gorgeous pastel pink color palette, a custom *Pacifico* font, and cute polka-dot backgrounds.
* **Cute Visuals:** A pink snake wearing a rotating ribbon, eating custom-drawn strawberries with sparkles ✨.
* **Progressive Difficulty:** The game starts at a relaxed pace but speeds up as you eat more strawberries to keep you on your toes!
* **Web Compatible:** Fully playable in the web browser using WebAssembly via `pygbag`.

## 🎮 How to Play
* **Arrow Keys**: Move your snake UP, DOWN, LEFT, and RIGHT.
* **SPACE**: Start the game, Pause the game, or play again after a Game Over.
* **Goal**: Eat as many strawberries as you can without hitting the walls or your own tail!

## 🚀 Running Locally

1. Ensure you have Python installed.
2. Install Pygame:
   ```bash
   pip install pygame
   ```
3. Run the game natively:
   ```bash
   python main.py
   ```
